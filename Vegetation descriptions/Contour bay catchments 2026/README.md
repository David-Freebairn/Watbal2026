# Contour bay catchment vege files (revised November 2026)

Wheat treatment descriptions for the Greenmount, Greenwood and Wallumbilla contour bay catchment studies (Southern Queensland small catchment data: https://github.com/David-Freebairn/Southern-Queensland-small-catchment-data).

Fallow residue in each file was refitted to the residue cover measured on those catchments, using one rule for all files: a non-increasing curve fitted to measured fallow cover by days since harvest. Green cover, root depth and planting day are as in the original files, and no multipliers are used. Old and new values, and the full joint calibration these files were used in, are in `calibration/joint_2026/` of the data repository.
